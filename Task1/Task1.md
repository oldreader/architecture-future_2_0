# Проблемы

1. Интеграция Microsoft SQL-сервер с Power BI обладает низкой наблюдаемостью. Нет ясности как быстро у нас процессятся данные. 
2. Microsoft SQL-сервер - является бутылочным горлышком - все доработки завязаны на команду DWH
3. Нет возможности подключать другие источники данных 
4Нет возможности гибко строить разные ветрины с Microsoft SQL-сервер

### Must Have

1. Организовать наблюдаемость для анализа текущих проблем. В этом нам поможет внедрение airflow. Мы сможем в онлайн режиме наблдать за ошибками загрузки данных и т.д.

### Should have

2. Организовать работу через единый шлюз работы с данными. В этом нам поможет на первом этапе Dremio. Он будет единым хранилищем.
3. Перевод на единую платформу datahub. Она будет интегрироваться с Dremio, как источником данных и предоставлять sdk для всх остальных систем в компании. 
4. Перевод витрин на работу через datahub.
